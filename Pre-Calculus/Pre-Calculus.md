# Pre-Calculus

## Summary

Pre-calculus builds the function language, algebraic techniques, and trigonometry needed for limits, derivatives, and integrals. This hub organizes the path from functions through polynomials, exponentials/logarithms, and trigonometry into calculus readiness.

## Prerequisites

Prerequisites: high-school algebra (equations, inequalities, graphing on the coordinate plane). Optional geometry background helps with trigonometry.

## Learning order

1. [[Functions]] — domain, range, graphs, composition, inverses
2. [[Polynomials and Rational Functions]] — zeros, end behavior, asymptotes
3. [[Exponentials and Logarithms]] — growth/decay, log laws, change of base
4. [[Trigonometry]] — unit circle, six ratios, identities, common angles

## How to use these notes

- Read each note in order unless a prerequisite line says otherwise.
- Work the single example in each note before moving on.
- When a formula appears, check the **Conditions / Assumptions** section first.
